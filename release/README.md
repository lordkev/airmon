# AirMon prototype r0.1 deliverables

`firmware/` contains the four USB flash images, application-only OTA image, manifest, checksums, flash argument file, and dependency licenses. Flash instructions are in [docs/FIRMWARE.md](../docs/FIRMWARE.md).

Manufacturing files remain in [hardware/exports](../hardware/exports/), BOMs in [hardware](../hardware/), and print files in [enclosure/stl](../enclosure/stl/). This avoids maintaining duplicate copies with different revisions. The repository archive includes all of them.

**Prototype hold:** board-side connector identification, supplied PM socket fit, and physical electrical/mechanical/firmware tests are still pending. See [VALIDATION.md](../docs/VALIDATION.md). The renders illustrate the CAD design; they are not photographs of a tested product.
