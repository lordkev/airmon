History is held in memory and resets when the device restarts. Gaps represent unavailable readings.

VOC and NOx are relative gas indices. CO₂ is measured by the optional SCD40. Missing sensors are shown as not installed.

Administrator access

Find the administrator token on the device under Settings → Wi-Fi setup / credentials. It is kept only for this browser session.

Device and Wi-Fi

New Wi-Fi credentials are saved only after a successful connection. Setup AP closes 60 seconds after saving.

Measurement settings

Enable automatic baseline calibration only when the sensor regularly sees fresh outdoor-equivalent air. Leave it disabled for continuously occupied or poorly ventilated spaces.

Home Assistant / MQTT

The monitor publishes sensor discovery automatically when connected to your MQTT broker.

Use mqtts:// for TLS with a publicly trusted server certificate. The dashboard itself uses local HTTP.

Calibration

For CO₂, use a known reference concentration and allow at least three minutes of continuous operation in stable air. Do not assume indoor air is 400 ppm.

Firmware update

Choose the AirMon application .bin for this board. Keep USB power connected during the update. The previous image is retained if validation fails.
